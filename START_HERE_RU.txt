MUSHROOM HUNT — FOREST V2 (NEW TEXTURES + SEAMLESS MAP BORDER)
===============================================================

Это улучшенная версия последней Mushroom Hunt Complete с 3D-руками WRAD ARMS.
Новая версия добавляет настоящие CC0 PBR-текстуры, каменную гряду по всему
периметру, непроходимый барьер в толще скал и большой лес за скалами.
Грибы, управление, анимации и задача «собрать 5 грибов» сохраняются.

В АРХИВЕ ДВА СПОСОБА УСТАНОВКИ — ВЫБЕРИ ОДИН

[A] ЕСЛИ ТЫ УЖЕ УСТАНОВИЛ ПОСЛЕДНИЙ MushroomHuntComplete НА КОМПЬЮТЕРЕ

1. Полностью распакуй архив в обычную папку Windows.
2. Закрой Unity Editor и сделай копию исходной папки проекта на всякий случай.
3. Запусти UPGRADE_EXISTING_PROJECT.bat.
4. Введи полный путь к папке MushroomHuntComplete (там должны быть Assets,
   Packages и ProjectSettings). Можно вставить путь из Проводника.
5. Скрипт создаст резервную копию Forest.unity, установит только новый Editor-
   скрипт и 6 бесплатных PBR-текстур. Твой код рук и геймплея НЕ переписывается.
6. Открой ту же папку в Unity Hub. Новая лесная сцена создастся автоматически
   после компиляции. Если не появится, нажми:
   Mushroom Hunt > Environment > Apply forest textures and rocky boundary.
7. Нажми Play: проверь скалы, лес за скалами и невозможность выйти за пределы.

[B] ЕСЛИ ТЫ ЕЩЁ НЕ УСТАНОВИЛ ПРЕДЫДУЩИЙ ПРОЕКТ ИЛИ НУЖНА СВЕЖАЯ КОПИЯ

1. Полностью распакуй архив.
2. С интернетом запусти SETUP_PROJECT.bat.
3. После SUCCESS появится папка MushroomHuntForestV2: полноценный Unity-проект.
4. Unity Hub > Add project from disk > выбрать MushroomHuntForestV2.
5. Желательная версия Unity: 6000.6.2f1, Built-in Render Pipeline.
6. При первом открытии дождись импорта. Unity автоматически настроит руки,
   сбор грибов и улучшение леса. В сцене открой Forest.unity, затем Play.
7. Для Windows: Mushroom Hunt > Build Windows. Нужны .exe И папка _Data.

ЧТО ИМЕННО ИЗМЕНИТСЯ
- Лесная почва: 2K diffuse+normal PBR «Forest Ground 01» с листьями и хвоей.
- Камни: 2K diffuse+normal PBR «Mossy Rock». На существующих и новых камнях.
- Кора: 1K diffuse+normal PBR «Bark Brown 02» (только на объектах, которые
  реально называются trunk/wood/bark; листья останутся зелёными).
- Земля расширится с 250 до 560 метров в ширину.
- На радиусе примерно 72–80 м появится неровная каменная гряда с валунами.
- Внутри неё 96 перекрывающихся коллайдеров без «дыр» по окружности.
- За скалами: 260 деревьев, 88 камней, 115 объектов подлеска.
- Туман мягко скрывает дальнейшую границу мира.
- Первоначальные объекты с грибами и их позиции сохраняются.

ГДЕ ИЗМЕНИТЬ НАСТРОЙКИ
Assets/Editor/MushroomEnvironmentUpgrade.cs
Пункт меню: Mushroom Hunt > Environment > Apply forest textures and rocky boundary
При повторном запуске сгенерированный слой создаётся заново, исходный лес
и сцена с грибами не перегенерируются. Для возврата первоначальной сцены
используй резервную копию Forest_before_EnvironmentV2*.unity.bak.

СЕРВИСНЫЕ ОГРАНИЧЕНИЯ
- Этот ZIP не содержит большой исходный Unity-проект и не содержит готовый EXE.
- Понадобится интернет: GitHub (для варианта B) и dl.polyhaven.org (A/B).
- В этой среде Unity Editor не запускался. Проект и сцена подготовлены кодом,
  финальный внешний вид/совместимость нужно проверить в Unity на Windows.
- Новые текстуры/модели загружаются при УСТАНОВКЕ, не в работающей игре.
- Если Unity не обновила сцену автоматически, воспользуйся ручной командой.
- Не запускай Mushroom Hunt > Create playable scene на твоей готовой сцене:
  этот инструмент создаёт лес с нуля и удаляет ручные изменения.
